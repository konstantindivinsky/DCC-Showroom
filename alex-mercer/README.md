# Alex Mercer | Creative Director

A responsive, fully coded single-page portfolio inspired by the supplied visual reference. This is a showroom example, not a reusable client template.

## Features

- Full editorial hero with angled portrait
- Three interactive project case-study dialogs
- Career timeline, section navigation, and mobile menu
- Email and telephone contact links
- Keyboard navigation and reduced-motion support
- Local assets, no external dependencies

## Deploy

For HestiaCP, copy the contents of this folder into a website public_html directory. For the DCC-Showroom site, this example lives at /alex-mercer/. All paths are relative.

## Demo content

Alex Mercer, the portfolio projects and roles, and the contact details are illustrative, not verified. Replace these before using as a real client website. Photography is cropped from the user-provided reference. Social links show a placeholder disclosure rather than link to invented profiles.

## Files

index.html, styles.css, script.js, assets/monogram.svg and local JPEG images.
