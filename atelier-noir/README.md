# Atelier Noir | Showroom Website

A responsive, dependency-free, static restaurant concept built from the supplied Atelier Noir visual reference.

## Deployment

1. Extract the ZIP.
2. Upload **all the contents** (including `assets/`) into the intended Hestia web domain's `public_html/` directory.
3. Visit the domain. No Node.js, PHP, database, build step, or external font/image service is required.

## Demonstration behavior

- Navigation scrolls to real content sections.
- The hero reservation form pre-fills a larger reservation preview.
- The preview validates the date, guest count, time, name and email, then displays a local demo summary. **No request is transmitted; no real table is booked.** Connect a backend before using this publicly as a live reservation system.
- The seasonal and garden menu tabs change real content.
- The gallery opens photos in a keyboard-navigable lightbox.
- Mobile navigation opens and closes, including Escape support.

## Assets and content

Photographic assets are extracted from the visual reference provided for this design concept. The sample menus, editorial quotes, and chef identity are illustrative, not verifiable claims or live business data. Replace them with approved client content and appropriately licensed full-resolution photos before publishing for a client.

## Files

- `index.html`: page content and accessible structure
- `styles.css`: desktop, tablet and mobile design
- `script.js`: navigation, forms, menu tabs and gallery
- `assets/`: bundled WebP photos and favicon
