# Iron & Road Motorcycles

Fully functional, mobile-first standalone website concept for the DCC Showroom project.

## What this is

- **Website #2** in the showroom inspiration series.
- Based on the provided Iron & Road visual reference.
- The eventual *showroom index/selector* will be built after the standalone examples are complete.
- The site is a fictional business demo, not a live booking or repair service.

## Deployment

The `index.html` in this GitHub folder is **self-contained**: HTML, CSS, JavaScript, logo and photos are included in one file. To deploy to Hestia, place `index.html` in a site's `public_html` directory. No backend, database or build system is needed.

A separate, more editable multi-file ZIP with optimized `assets/` is provided in the ChatGPT conversation.

## Functional features

Responsive navigation; service menu; five service detail cards; project stories; build details; ride feature; clubhouse section; service preselected booking modal; event interest dialog; copy-request support; input validation; keyboard-friendly dialogs.

## Demo limitations

Booking and event forms compose emails addressed to the reserved example domain `ironandroad.example`. They do **not** send submissions to a server or create confirmed reservations. Real phone numbers, shop hours, addresses, event schedules and form backend must be supplied before publishing for a customer.

Manufacturer names are provided as vehicle-make identifiers, without implying affiliation. Image compositions were cropped from the user-supplied visual reference. Replace them with licensed source images before launching a real client's website.

External Google Fonts load when available, with offline fallback fonts. No external JavaScript dependencies or CDNs.
