# James Morrison | Executive Leader & Strategic Advisor

This is a fully functional, responsive, static website concept, designed to closely follow the supplied reference screenshot. It is one standalone example for the DCC Showroom collection.

## Preview

Open `index.html` in a browser. No build step, dependencies, or server configuration are needed.

## Hestia deployment

Upload the contents of this folder (including the `assets` folder) to the desired domain's `public_html` directory. `index.html` must be at the document root. All asset paths are relative and also work in a subdirectory.

## What works

- Responsive desktop, tablet, and mobile layouts, including a keyboard-friendly mobile menu
- Same-page navigation to About, Experience, Insights, and Contact
- Experience and leadership sections beyond the supplied visual reference
- Clickable insight perspectives displayed in accessible modal dialogs
- One-minute written introduction with optional browser-generated voice narration
- Contact form validation and an explicit demo confirmation
- Focus states, skip navigation, dialog close behavior, reduced-motion support, and semantic markup

## Before publishing as a real client's website

- This is a **showroom concept**. The supplied screenshot is the only source for the visual style and the 25+ years / leadership claims. All extended biography, experience, and insights copy is illustrative, not verified biographical information.
- Portrait and architecture assets are crops of the supplied design screenshot. Replace them with suitably licensed, high-resolution original media for a real engagement.
- Contact form deliberately **does not send or store data**. Connect it to a real backend/form handler with appropriate anti-spam and privacy controls before accepting inquiries. Do not assume it is connected because it validates.
- Confirm the client's actual biography, credentials, career accomplishments, contact details, privacy language, and approvals.
- The introduction narration is text-to-speech, not an uploaded video.

## Files

- `script.js`: navigation, dialogs, narration, and form demonstration
