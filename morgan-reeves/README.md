# Morgan Reeves | Technology Consultant

A responsive, static website concept for the DCC Showroom project, modeled on the supplied Morgan Reeves reference image.

## Files

- `index.html` — page content and all dialogs
- `styles.css` — desktop and mobile styles
- `script.js` — navigation, service-to-consultation interaction, contact demo, articles, and 60-second presentation
- `assets/` — optimized local imagery, mountain illustration, and SVG favicon

No frontend frameworks, package managers, build step, database, tracking, or third-party requests are required.

## Deploy to Hestia

1. Extract the ZIP locally.
2. Upload **the contents** of `morgan-reeves-site/` into the domain's `public_html` folder (the `index.html` file should be in the web root).
3. Confirm your site's domain serves `index.html` over HTTPS.

All links to local CSS, JS, and images are relative, so the site can also run from a subfolder or be included in the eventual showroom. 

## Functional demo features

- Responsive sticky navigation with mobile menu and live active-section highlighting
- All five navigation destinations scroll to live page sections
- Four clickable service cards pre-select service in the consultation form
- Consultation buttons open an accessible native dialog
- Form validates fields and generates a **copyable** inquiry preview locally; it does **not** send a message or collect data remotely
- 60-second animated/silent overview with pause, resume, next, and replay
- Three complete insight articles open as dialogs

## Production checklist

The source design is inspirational. The portrait and desktop imagery are optimized crops from the user-provided reference, and the mountain landscape is a locally generated vector illustration. Replace imagery as needed before commercial publishing.

**This is a fictional/showroom concept, not a verified client profile.** The name, businesses, testimonials, quantitative results, and phone number are example content and must be verified or replaced before publishing as a real consultancy. The telephone in the sample matches the reference mockup; it is not a verified contact channel. The request form is intentionally offline/demo-only. Connect a real backend or form provider before accepting inquiries.

No em dashes are used in the site copy.
