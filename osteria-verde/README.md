# Osteria Verde - Website Showroom Concept

A responsive, static restaurant website recreation based on the supplied Osteria Verde design reference. HTML, CSS and JavaScript are framework-free. Its page visuals were extracted from the reference image provided for this design exercise.

## Deployment to Hestia

Extract the ZIP and upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, and the `assets/` directory together into the site's `public_html` directory. Open the domain in a browser. No build tools, package installation or database are needed.

## Interactive areas

- Navigation and mobile menu
- Menu categories: Antipasti, Primi, Secondi, Dolci
- Wine pairing details
- Private-dining information
- Reservation form with local preview

**Important:** This is a showroom concept, not an operating restaurant's live site. The reservation form intentionally does not submit, transmit, or store a reservation. Sample times are not real-time availability. Menu additions and wine pairings in interactive popups are illustrative. Real-world launch requires confirmed business content and a connected reservation solution.

## Fonts

The design uses Cormorant Garamond, Caveat and DM Sans via Google Fonts with system font fallbacks. Photographic images and parchment textures are bundled with the website, so they do not depend on external image hosts.
