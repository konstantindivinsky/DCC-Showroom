# Precision Diagnostics - Website Showroom Concept

A responsive, functional, static website built as one of the **DCC Website Showroom** inspirational concepts. This design is intended to start a client design conversation and is not a turnkey business template.

## Preview and installation

1. Open `index.html` locally or serve this folder with any static web server.
2. For Hestia, upload the contents of this directory to the domain's `public_html/` directory. No PHP, Node, build step, database or CDN is required.
3. Replace the concept business details, images, and illustrative credential content before production publication.

## Features

- Mobile-first navigation with accessible toggle and services menu
- Detailed warning light guide with six interactive indicators and safety guidance
- Four-step diagnostic process and four informative service cards
- FAQ accordion and direct phone links
- Service inquiry form with client-side validation and copyable summary. **No appointments are transmitted, no backend is connected.**
- Keyboard-friendly dialogs and reduced-motion support
- All image and script assets bundled locally, no external dependencies

## Files

- `index.html` - semantic page structure and interactive dialog markup
- `styles.css` - full responsive design
- `script.js` - navigation, warning light information, service inquiry behavior
- `assets/` - branding and imagery derived from the supplied visual design reference

## Production considerations

- Confirm business name, address, contact information, offered services, credentials and permission to display any organization marks.
- Connect booking to a real scheduling system or replace with a valid contact method. Do not display a fake success message.
- Configure privacy and accessibility review before production use.
- The current design uses an example telephone number and location from the visual reference; this is not a claim that the business exists.
