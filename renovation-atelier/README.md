THE RENOVATION ATELIER
Historic home restoration website concept

DEPLOYMENT
- Unzip the contents of this folder into the document root of your Hestia-hosted domain (typically public_html).
- index.html must be in the document root, beside styles.css and script.js.
- No build tools, databases, PHP, or server-side services are required.
- All photography is derived from the visual reference supplied for this design.
- Google Fonts are loaded if internet access permits. The design includes local fallback fonts.

FEATURES
- Fully responsive editorial homepage and mobile navigation
- Working anchor links for Approach, Restorations, Studio Journal, About, and Contact
- Interactive project and journal story views with keyboard-accessible dialogs
- Accessible image descriptions and reduced-motion support
- Contact inquiry uses the visitor's email application; no data is sent to or stored on the site

DEMO NOTE
This is an inspirational showroom website. The studio identity, project names, and stories are example content. Replace sample content, imagery, and inquiry handling before using it for a real business. The inquiry form deliberately does not specify a recipient because no valid recipient address was provided.
