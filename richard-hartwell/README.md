# Richard Hartwell | Attorney Website Showroom Concept

Responsive static law-firm website inspired by the approved reference design, part of the **DCC-Showroom** inspiration collection.

## Viewing

Open [index.html](./index.html) in a web browser. The page is fully self-contained, with its CSS, JavaScript, and photographic image assets embedded. No build tools, third-party libraries, tracking scripts, or external requests are required.

## Deployment to Hestia

Upload `index.html` to the desired domain's `public_html` directory. It works as an independent site. For deployment at a subfolder, retain its existing filename.

## Features

- Responsive mobile-first layout and navigation
- Hero, services, biography, credentials, testimonials, insights, and contact sections
- Practice-area interactions and expandable attorney biography
- Demonstration consultation form with client-side validation

## Showroom and legal-use disclosures

This is a **fictional demonstration**, not the actual website of an attorney. Names, credentials, legal status, client testimonials, addresses, phone numbers, and case descriptions are illustrative and have not been independently verified. Replace and confirm all such details before any real-world use, and comply with applicable attorney advertising rules.

The consultation form deliberately does **not** transmit, save, or submit data. Connect a secure real intake provider and add appropriate disclosures before deploying for an actual client.

Image assets are cropped from the design reference supplied for this concept. Verify rights to use any photography or graphic material before publishing commercially.

This example is independent of the eventual DCC showroom navigation, which will be assembled later.
