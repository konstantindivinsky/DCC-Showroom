# Riverside Wellness — Website Showroom Concept

A fully static, responsive, no-build demonstration website based closely on the supplied visual reference.

## Deploy to Hestia

Upload the **contents** of this directory (not a nested enclosing folder) into the domain's `public_html` directory. `index.html` is the entry point. No PHP, database, package manager, node service, or compilation is needed.

## Features

- Desktop design follows the reference's structure and color palette.
- Mobile-first layout with working navigation. Responsive refinements tested at 320–1440px, including desktop-mode phone and compact tablet widths.
- Split hero headline and appointment buttons remain clear of the portrait at medium desktop widths; clinic details and credentials reflow without horizontal scrolling.
- Interactive testimonial carousel and FAQ accordions.
- Appointment-request **demonstration** with browser-side preview and copy button. No request is transmitted, persisted, or booked.
- Local image assets cropped from the user-provided reference. No third-party tracking, CDN assets, or runtime dependencies.
- Semantic markup, alt text, keyboard-accessible controls, reduced-motion support.

## Important before client publication

All names, credentials, testimonials, contact information, and practice details are **illustrative** and must be replaced and independently verified before publication. The appointment demo must be connected to an approved scheduling service before it can receive real appointments. Do not use this demo to collect sensitive patient information.

This website is an original development of the provided reference layout for visual concept purposes.
