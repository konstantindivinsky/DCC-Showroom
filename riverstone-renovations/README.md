# Riverstone Home Renovations | Website Concept

A responsive, framework-free static website inspired by the supplied design reference. This is a **showroom concept**, not a working business website.

## Included features

- Functional, keyboard-accessible before-and-after comparison slider
- Responsive, accessible desktop and mobile navigation
- Interactive renovation categories and project filtering
- Project detail popups with Escape and backdrop dismissal
- Services, process, about and consultation sections
- Consultation form that validates fields and prepares an inquiry locally
- Bundled images and assets, no external fonts, JavaScript libraries, CDNs or APIs
- Category card arrows spaced away from text, including narrow desktop previews
- Gallery images eagerly loaded to prevent empty cards in local previews
- Reduced-motion, semantic markup and keyboard support

## Hestia deployment

1. Extract the ZIP archive.
2. Upload the **contents of the ZIP** into your desired domain's `public_html` folder.
3. Open the domain in a browser. No Node, PHP, database or build step is required.

The project can be placed under a subpath or a showroom iframe as all links and asset paths are relative.

## Important demo notes

The project facts, name, square footage, location, duration, and any experience claims in the supplied visual are **illustrative**. They should be verified or replaced before representing an actual contractor.

Photos for the hero and cards were isolated from the user-supplied screenshot. They are intended for **internal concept and client discussion use**. Before publishing a real commercial client site, replace these with appropriately licensed, high-resolution photography or actual client-approved project photography. The original reference was only 1536 by 1024, so these photos do not have full original camera resolution.

The consultation form intentionally **does not transmit or store** visitor data. It prepares an inquiry that can be copied. Connect to an authorized backend, form service, or mail provider before launch.

## Files

- `index.html`: complete site markup
- `css/styles.css`: responsive design and animations
- `js/main.js`: before/after slider, filters, modal, nav, and local form
