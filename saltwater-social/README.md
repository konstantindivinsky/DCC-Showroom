# Saltwater Social — Showroom Website Concept

A responsive, static, **single-page demonstration site** built from the provided Saltwater Social visual reference. Designed for inclusion as an independent example in the DCC Website Showroom project.

## Deploy to Hestia

1. Extract the ZIP.
2. Upload the contents of the `saltwater-social` folder (`index.html`, `styles.css`, `script.js`, `assets/`) to the domain's `public_html` folder.
3. Visit the domain. No build step, server language, database, or third-party packages are required.

## What works

- Responsive desktop, tablet, and mobile layouts.
- Mobile navigation.
- Accessible menu dialog with four switchable menu categories.
- Reservation date/party/time selector and interactive reservation **preview**.
- Private-event inquiry form with client-side validation and preview confirmation.
- Click-to-enlarge photo gallery.
- Page-section links, keyboard-accessible modals, and close actions.

## Important demo limits

This is **not a live restaurant booking site**. The booking interface does not access real table availability or submit reservations. The inquiry form does not send or save details. Menu prices, location, and hours are illustrative, based on the provided concept design rather than verified business information.

**Photography:** The demo images were cropped from the reference image supplied for this design exercise. Before using for a public business site, replace them with original photographs or properly licensed image assets. These embedded reference images are suitable only for evaluating the visual concept with authorization from the rights holder.

## File structure

- `index.html`: Site content and interactive dialogs.
- `styles.css`: Responsive layout and styles.
- `script.js`: All local interactivity.
- `assets/`: Locally stored reference imagery and favicon.

No tracking scripts, webfont downloads, external network requests, or third-party JavaScript dependencies.
