# Sunday Table — Website Showroom Concept

A responsive, single-page, static restaurant website inspired by the supplied Sunday Table reference image.

## Files

- `index.html` – semantic page markup
- `styles.css` – desktop, tablet and mobile styling
- `app.js` – interactive menu filters, order preview/cart, and reservation preview
- `assets/` – bundled site images and favicon

## Deploying with Hestia

Upload and extract the ZIP contents directly into the target domain's `public_html` folder. `index.html` must be at the root of `public_html`. No build step, runtime, database, npm packages, or internet access is required.

## Features

- Responsive café layout, including a tailored mobile hero
- Breakfast, lunch, bowls and salads, drinks and sides menu filters
- Functional sample basket with item quantity adjustments, subtotal and local browser storage
- Example table-request form with browser date/time validation
- Responsive mobile navigation
- Accessible dialog controls and keyboard support

## Important showroom notes

This is a fictional sample café. Address, testimonials, imagery, hours, prices, and menu are presentation content, not live business data. The cart, checkout, reservation form, map/directions and social buttons are explicitly marked as showroom demonstrations. No real payments, online orders or table bookings take place. Connect a restaurant's own service providers and replace placeholder business information before publishing for a real client.

The imagery is derived from the reference image provided to create this concept. Use independently licensed photographs if adapting the design to an unrelated commercial business.
