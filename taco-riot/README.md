# Taco Riot | Website Showroom Concept

A complete, responsive and dependency-free static website based on the supplied Taco Riot design reference.

## Deployment to Hestia

1. Extract the ZIP archive.
2. Upload the contents of the `taco-riot-site` folder into your site's `public_html` directory (or a subdirectory).
3. Open `index.html` through your domain. No installation, server-side dependencies, build tools or database are necessary.

## Interactions

- Mobile navigation, anchored site sections and live menu category switching
- Menu items, featured combo, special, and merchandise added to a working demo cart
- Quantity controls, subtotal and cart state saved in the local browser
- Pickup / delivery / catering UI, example calendar and feed likes
- Keyboard-accessible cart and merchandise popups, ESC close behavior
- All images, artwork and stylesheets are local assets: **no external requests required**

## Important

This is a **website showroom concept**, not a live commercial restaurant storefront. Menu prices, events, merchandise, hours and locations are placeholders. Checkout, email signups and event RSVPs deliberately **do not** process a transaction or send personal information.

Creative assets are constructed from the user-provided design reference plus original CSS/SVG textures and artwork. Do not present this mockup as a real restaurant website until branding, content, image rights and real business information have been approved.
